# Python Programming Fundamentals

A collection of Python programs I developed while studying computer programming at **McLennan Community College**.

These projects helped me build a foundation in Python and practice turning problems into logical, working programs. The repository includes calculators, games, data structures, file-based exercises, and interactive applications.

## Skills & Concepts

* Python
* Programming logic
* Variables and data types
* User input and output
* Conditional statements
* Loops and iteration
* Functions
* Lists and dictionaries
* String manipulation
* Error handling
* Input validation
* Random number generation
* Basic data processing
* Problem-solving
* Interactive console applications

## Projects

### Age Calculator

A Python program that works with user-provided information to calculate age-related results.

**Concepts:** Variables, user input, calculations, and formatted output.

### Budget Calculator

A program for working with income and expenses to calculate and organize a basic budget.

**Concepts:** Variables, arithmetic operations, user input, and calculations.

### Contact Manager

An interactive program for storing and managing contact information.

**Concepts:** Lists, dictionaries, user input, functions, and data organization.

### Employee Logging System

An interactive employee-record program that creates employee records, generates unique employee IDs, validates input, and prevents duplicate employee names.

**Concepts:** Dictionaries, lists, functions, loops, random number generation, and input validation.

### Grade Calculator

Calculates and evaluates grades using numerical scores and conditional logic.

**Concepts:** Conditional statements, comparison operators, user input, and decision-making.

### Interest Calculation

Performs financial interest calculations using user-provided information.

**Concepts:** Variables, arithmetic operations, functions, and user input.

### Number Guessing Game

An interactive guessing game that uses random number generation and repeated guesses to determine whether the player has found the correct number.

**Concepts:** Random numbers, loops, conditionals, user input, and program flow.

### Rock Paper Scissors

A console-based Rock Paper Scissors game that allows a user to play against a computer-generated choice.

**Concepts:** Random number generation, conditional logic, user input, and game logic.

### Student Information Manager

A Python program that uses nested dictionaries to organize student information such as names, IDs, GPAs, credits, and grades.

**Concepts:** Dictionaries, nested data structures, loops, data access, and data management.

### String Replacement Tool

A text-processing program that allows users to replace portions of a string based on their input.

**Concepts:** Strings, string methods, user input, and text processing.

### Number Accumulation

A function-based exercise that processes a list of numbers and calculates a running total.

**Concepts:** Functions, parameters, lists, loops, return values, and error handling.

## What I Learned

These projects helped me develop the fundamentals of Python programming and become more comfortable breaking a problem down into smaller steps.

I practiced writing functions, working with lists and dictionaries, handling user input, using loops and conditional statements, and creating programs that respond to user interactions.

The projects also gave me experience with basic error handling and input validation, helping me understand how programs should respond when users provide unexpected information.
